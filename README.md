# Programarea Algoritmilor · INFO ID 26

Platformă de studiu pentru Python și Programarea Algoritmilor, organizată după materia profesorului Ceaușescu Ciprian.

[Deschide cursul](https://pa.infoid26.ro/)

## Ce include

- 5 lecții introductive de Python și 16 capitole de algoritmi.
- 91 de lecții, 260 de exerciții și întrebări de consolidare.
- Editor Python cu verificare, indicii și rezolvări explicate.
- Progres sincronizat între dispozitive prin contul Microsoft universitar.

## Utilizare

Alege o lecție din traseu, parcurge explicațiile și scrie soluția. Apasă **Verifică** sau **Ctrl + Enter** pentru evaluare. Toate lecțiile sunt accesibile pentru studiu și recapitulare.

Conectarea este disponibilă pentru conturile `@s.unibuc.ro` și `@unibuc.ro`. Fără cont, progresul rămâne în browser. La Logout, progresul sincronizat rămâne în cont, iar copia locală a contului este eliminată.

## Conținut și verificare

Exercițiile sunt materiale de pregătire, nu subiecte oficiale de examen. Testele verifică rezultatele pentru cazurile incluse; nu demonstrează complexitatea sau folosirea metodei cerute. Modulele, testarea și obiectele sunt marcate ca suplimentare.

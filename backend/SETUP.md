# Cont universitar și progres

Conectarea cu Microsoft este disponibilă pentru conturile universitare `@s.unibuc.ro` și `@unibuc.ro`. După conectare, interfața afișează numele contului și opțiunea Logout.

Codul, rezultatele verificărilor, răspunsurile corecte și poziția în curs se salvează automat în cont și pot fi recuperate pe alt dispozitiv. Salvarea este confirmată prin mesajul de sincronizare din interfață.

Fără conectare, progresul este păstrat în browser. Ștergerea datelor site-ului poate elimina acest progres.

Dacă sincronizarea eșuează sau există modificări incompatibile ale aceleiași soluții, copia locală este păstrată. Opțiunile afișate permit recuperarea progresului fără suprascriere automată.

Logout finalizează sincronizarea, elimină copia locală a contului și închide sesiunea site-ului. Progresul salvat în cont rămâne disponibil la următoarea conectare.
